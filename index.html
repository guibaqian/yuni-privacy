余你五子棋 隐私政策

生效 / 最近更新日期：2026-11-08
开发者 / 运营者：魏俊辉
适用范围：微信小游戏「余你五子棋」（AppID：wx92e438e4c635f1a6）及独立应用 / Google Play 版本（包名：com.guibaqian.yunigomoku）

欢迎使用「余你五子棋」（以下简称「本应用」或「本游戏」）。我们重视您的隐私。本政策说明我们如何收集、使用、存储、共享与保护您的个人信息，以及您享有的权利。使用本应用即表示您已阅读并理解本政策；若不同意，请停止使用。

本应用面向一般用户，不专门面向儿童。我们不会要求您提供身份证号、银行卡完整卡号等敏感证件信息作为使用前提；也不强制绑定手机号或邮箱。

一、我们处理的信息

为实现基本功能，本应用可能收集或处理以下信息（具体以您实际使用的版本与授权为准）：

1. 账号与身份

  • 微信小游戏：使用微信身份登录（微信为本游戏分配的匿名标识 / openid 等），无需额外注册。系统可分配游戏内玩家 ID，用于加好友与找回数据。
  • 独立应用 / Google Play：若您登录或绑定账号，可能包括昵称、头像、账号标识等您主动提供或第三方授权提供的信息。
  • 昵称与头像（可选）：仅当您在设置中主动选择「使用微信头像和昵称」并在微信弹窗同意后，才读取微信昵称与头像用于展示；拒绝不影响游玩。您可随时换回自定义并删除已存的微信头像。昵称等文字可能经内容安全检测。

2. 游戏数据

  • 对局与战绩、进度、成就、物品 / 鱼鱼币、设置偏好、好友关系等，用于保存进度、匹配对局、排行榜、跨设备同步与改进体验。
  • 完整棋谱主要保存在本机；云端多为摘要或对战所需数据。
  • 私信：仅双方可见，通常保留每对最近一定条数（如最近 200 条）。

3. 您主动提交的内容（UGC）

  • 昵称、短语、聊天 / 私信、举报说明等。
  • 意见反馈内容（文字和截图）：您在「意见反馈」中主动提交的文字，以及您选中的照片或视频信息（截图，通常最多 3 张）——仅用于排查问题与回复，不作他用。

4. 相册 / 相机（仅反馈）

仅在您主动添加反馈截图时，才读取您选中的图片并上传云端。不作广告画像或其他用途。若未使用意见反馈截图功能，不会因此申请相册 / 相机权限。

5. 设备、日志与网络信息

  • 提交意见反馈时，可能附带机型与系统版本，便于排查兼容问题。
  • 为保障安全、防作弊与风控，可能处理必要的网络地址（IP）、应用版本、崩溃日志或必要的网络诊断信息。
  • 独立应用版本可能涉及设备型号、操作系统版本及必要的设备标识（如有），用于保障安全与排查故障。

6. 剪贴板

仅在您点击「复制」时，写入玩家 ID 或房间号等；不读取剪贴板内容。

7. 订阅消息 / 通知（可选）

若您在点击后同意微信订阅消息（如好友私信提醒），我们仅按您授权的次数发送对应通知；您可在微信设置中管理或关闭。

8. 广告与支付（如开通）

  • 激励视频广告：若出现「看视频」入口并由后台配置广告位，由微信广告组件等展示；是否观看完全自愿。我们不因此额外收集手机号或通讯录。
  • 应用内购买：若您在 Google Play 等渠道购买，支付由相应支付服务处理；我们通常仅收到订单结果（是否成功、商品类型等），不收集完整银行卡号。

9. 我们不收集 / 暂不申请

  • 不获取位置、通讯录、手机号作为常规功能。
  • 语音连麦尚未开放：开放前不会申请麦克风；开放时会另行说明并征得同意。

二、我们如何使用信息

  • 提供、维护与改进对局、好友、私信、排行、商店、反馈等功能；
  • 账号安全、防作弊、内容安全审核与违规处理；
  • 客户支持、问题排查与开发者回复；
  • 履行法律法规及微信公众平台 / 应用商店审核与合规披露要求。

我们不会将您的个人信息出售给第三方。

三、第三方 SDK / 服务商

为实现功能，本应用可能接入以下类型的第三方能力（以实际版本为准）。第三方将按其隐私政策处理相关数据：

  • 微信开放平台 / 微信小游戏与登录相关能力（账号登录、内容安全检测、云开发、广告组件、订阅消息等）；
  • 微信云开发（腾讯云）：游戏云端数据存储与云函数；
  • Google Play 服务（独立应用版本的分发、登录或支付相关能力，如开通）。

除上述为实现功能所必需、法律法规要求，或取得您明确同意外，我们不会向无关第三方共享您的个人信息。

四、信息存储与保护

  • 微信小游戏相关数据主要存于微信云开发（腾讯云）中国境内，仅本游戏云函数等授权服务可访问。
  • 独立应用版本的信息可能存储于我们使用的云服务所在地区。
  • 我们采取合理的技术与管理措施保护信息安全；但请理解互联网环境无法保证绝对安全。
  • 我们仅在实现本政策所述目的所需期间，或按法律要求保留信息；账号存续期间保留必要数据；删除 / 注销后按法规与平台规则处理（删除或匿名化，法律法规另有规定的除外）。

五、您的权利

  • 可随时修改昵称 / 头像，换回自定义头像，拉黑玩家或解除拉黑。
  • 可撤回微信侧相关授权（在系统 / 微信设置中管理）。
  • 可通过应用内「意见反馈」联系我们，查询、更正、删除个人信息或提出投诉建议；我们将在核实后尽快处理。
  • 删除账号数据：微信小游戏可通过右上角「···」→「反馈与投诉」提出，我们通常在 15 个工作日内处理；独立应用版本亦可通过下述联系方式提出注销 / 删除请求。
  • 关闭部分权限后，对应功能可能不可用，但不影响其他基本功能（法律法规另有要求的除外）。

六、未成年人

未成年人请在监护人陪同与同意下使用，并合理安排时间。本应用不专门面向 13 周岁以下儿童。如我们发现在未经监护人同意的情况下收集了儿童个人信息，将尽快删除。

七、政策更新

我们可能适时更新本政策。更新后将在本页面发布，并视情况通过应用内提示等方式告知。微信小游戏版本亦与公众平台「用户隐私保护指引」保持一致，请定期查阅。
